# C4 Architecture Model — Index

> The C4 model is the living architectural description of the system. The SA updates this after each epic. This file is the index; detail lives in level files.

## Level files

- `C4-L1-context.md` — System context: users, external systems, system boundary
- `C4-L2-containers.md` — Containers: Next.js app, Supabase (Postgres + Storage + Realtime), Clerk, Resend, Docuseal
- `C4-L3-components.md` — Components: modules within the Next.js app (auth, front-door, onboarding, engagements, files, messaging, notifications, admin)
- `C4-L4-code.md` — Code-level: key classes, hooks, server actions, route handlers

## Status

Initial — to be populated by the SA during the first epic's Close-prep phase.
