# Product Observations

> **Purpose:** Live product observations captured during sessions with the accountant (product owner) or from real usage of the portal. These inform requirement refinements, bug prioritization, and future epics.
>
> **Who writes here:** The main Claude Code session may append observations directly (per CLAUDE.md § Main Session Rules). All other requirements changes go through the RA agent.
>
> **Format per entry:**
> ```
> ### [YYYY-MM-DD] — <short title>
> **Source:** <session description, user report, or usage review>
> **Observation:** <what was observed>
> **Implication:** <possible requirement change, bug, or clarification needed>
> **Status:** Open | Incorporated | Declined
> ```
>
> The RA reads this file at the start of every invocation and acts on open entries.
