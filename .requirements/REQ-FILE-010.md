# REQ-FILE-010 — Accountant organizes engagement files into folders

## User need
An engagement can accumulate dozens of documents. Without structure the accountant can't find anything
and the client is overwhelmed. The accountant needs to organize an engagement's files into a folder
structure she controls, matching how she runs her practice.

## Proposed solution
Files within an engagement can be organized into folders. The accountant creates and manages the folder
structure for an engagement — adding, renaming, and arranging folders — and files are placed within
those folders.

## Acceptance criteria
- **AC-FILE-010-01** — Files within an engagement can be organized into folders.
- **AC-FILE-010-02** — The accountant can create, rename, and arrange the folders within an engagement.
- **AC-FILE-010-03** — A file can be placed within a folder of its engagement.
- **AC-FILE-010-04** — Management of the folder structure is an accountant capability; clients do not
  manage the folder structure.
