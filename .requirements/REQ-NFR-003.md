# REQ-NFR-003 — Web browser only in v1

## User need
The practice and its clients all work from desktop and laptop web browsers. Building or maintaining a
native mobile application in the first version would be effort spent on a delivery channel nobody needs
yet. v1 should target the web browser only and defer any native client.

## Normative criterion
- **AC-NFR-003-01** — The portal is delivered as a web application usable through a standard web browser;
  v1 ships no native mobile or desktop application.
